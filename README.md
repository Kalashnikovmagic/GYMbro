# GYMbro

Минималистичный PWA-дневник тренировок. Работает офлайн, сохраняет подходы на устройстве и показывает прогресс по каждому упражнению.

## Возможности
- упражнения и тренажёры;
- запись веса, повторений и заметки;
- история тренировок и график рабочего веса;
- подсказки по технике;
- личные ссылки на видео техники;
- установка на телефон или компьютер как приложение.

## Запуск
Это статическое приложение: откройте `index.html` через локальный сервер или включите GitHub Pages для репозитория.

> Данные сейчас хранятся только в браузере через LocalStorage. Облачная синхронизация — следующий этап.
